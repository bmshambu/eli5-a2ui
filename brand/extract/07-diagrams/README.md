# 07-diagrams: funnels, roadmaps, process flows and infographic elements

## templates/ (build-your-own, editable)
14 KPMG-styled diagram templates, 1600 × 900 (16:9), in the 2026 palette. Each comes as **.svg** (editable) and **.png** (preview, 1600 px).

| Template | Use it for |
|---|---|
| funnel-5-stage-vertical | Sales, conversion or pipeline funnel with numbers and stage-to-stage conversion |
| funnel-4-stage-dark | Pipeline funnel on KPMG blue, numbered descriptions on the right |

| roadmap-4-phase-chevrons | Phased programme roadmap with dates, activities and milestone diamonds |

| maturity-staircase-5-level | Maturity model (based on tech report figures 2–3) |
| pyramid-5-level | Capability or priority hierarchy |
| pillars-3-gradient-cards-dark | Three key messages with stats (style of tech report p10/p14/p19) |
| matrix-2x2-prioritisation | Value vs effort, risk vs impact and similar |
| kpi-row-6-icons | Headline numbers with the line icons below (style of annual report p6) |

**Editing**
- PowerPoint: Insert > Pictures > the .svg, then right-click > *Convert to Shape*. Every label becomes an editable text box and every shape can be recoloured.
- Figma, Illustrator, Inkscape: open the .svg directly. Shapes are grouped by stage/phase (`stage-1`, `phase-2`, `lane-3` …).
- Headings use *KPMG Bold*, falling back to Arial Narrow; body text uses Arial. If KPMG Bold is installed it is picked up automatically. The preview PNGs were rendered with a condensed substitute, so spacing can shift slightly.
- Light templates have a transparent background. The "-dark" ones carry the Cobalt-to-KPMG-Blue gradient.
- Sample text and numbers are placeholders, apart from the KPI row, which repeats the KPMG Denmark FY25 figures.

## icons/
Six line icons traced as true vectors from the KPMG Denmark Annual Report (p6): people-group, coins-percent, high-five, handshake, global-person, professional-woman. Each comes in blue (#00338D), cobalt (#1E49E2) and white as SVG plus a 512 px transparent PNG.

## from-pdfs/
High-resolution crops (about 2400 px wide) of the diagram-style elements that already exist in the 2026 PDFs, sorted by type:
- **roadmaps-and-timelines**: 8-step 2026 agenda (tech report p27), numbered contents grid (p2)
- **pillars-and-cards**: gradient card rows (tech report p10, p14, p19, p23), four-pillars panel (annual report p14)
- **maturity-and-progression**: maturity curve, step bars, adoption stacked columns (tech report p8–p9)
- **charts**: column, paired, split and stacked bar styles (tech report p16–p21, annual report p7)
- **stats-and-callouts**: ROI badges, stat panels, 55% callout, pull quote, research hero stats, KPI icon row
- **infographic-panels**: KPMG China Impact Plan "achievements at a glance" pages

None of the five PDFs contains a true funnel or Gantt-style roadmap, which is why those were built as templates. The crops are flattened images containing the original copy; use them as visual references or reuse them unchanged with attribution.
